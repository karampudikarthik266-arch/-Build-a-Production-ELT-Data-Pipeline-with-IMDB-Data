# -Build-a-Production-ELT-Data-Pipeline-with-IMDB-Data

## Project Overview

This project focuses on building an end-to-end, production-oriented ELT (Extract, Load, Transform) data pipeline using IMDb movie data.

The pipeline extracts movie information from the IMDb API using Python, orchestrates data ingestion workflows with Apache Airflow, stores raw datasets in Google Cloud Storage (GCS), and loads and transforms the data in Google BigQuery.

The processed data is then used to build analytical reports and interactive dashboards using Looker Studio.

## Technology Stack

**Python:** Data extraction and ingestion.

**Apache Airflow**: Workflow orchestration and scheduling.

**Google Cloud Storage:** Raw data storage.

**Google BigQuery:** Data warehousing and SQL transformations.

**Looker Studio:** Data visualization and reporting.

**Docker:** Containerization and local development.

**Git & GitHub:** Version control and project management.

## Project Objectives

Build an automated end-to-end ELT pipeline.

Extract IMDb movie data through API integration.

Implement workflow orchestration using Apache Airflow.

Store raw data in Google Cloud Storage.

Load and transform data using Google BigQuery.

Develop analytics-ready datasets.

Create interactive dashboards using Looker Studio.

Understand production-level data engineering practices.

## Architecture

IMDb API → Python → Apache Airflow → Google Cloud Storage → Google BigQuery → Looker Studio

## Learning Outcomes

This project provides hands-on experience with cloud-based data engineering, API integration, data ingestion, workflow orchestration, data warehousing, SQL transformations, and data visualization.
